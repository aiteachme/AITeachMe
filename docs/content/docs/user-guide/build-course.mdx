构建课程是 AITeachMe 的主路径。它会把你的目标和资料变成一个课程空间，然后围绕这门课生成后续学习资产。

## 一句话理解

构建课程不是“让 AI 回答一个问题”，而是创建一个可持续学习的空间。

这个空间里会沉淀：

- 资料和解析结果。
- 学习方案。
- 知识文档。
- 知识图谱。
- 对话、测验和学习画像。

## 写一个清楚的课程目标

推荐结构：

```text
我想学习/复习什么。需要覆盖哪些章节知识点。有没有资料、考试范围或时间限制。
```

示例：

```text
我想系统复习大学高数，范围包括极限、导数、中值定理、不定积分、定积分和应用。
```

如果已经上传资料，可以这样补充范围：

```text
根据我上传的课程资料，按考试范围整理一门考前复习课，重点覆盖章节、概念和常见题型。
```

不推荐只写：

```text
帮我学习这个。
```

系统很难仅凭这句话判断课程范围、难度和产出形式。

## 确认学习方案

提交目标后，系统会先生成学习方案。这个步骤很重要，因为它决定后续文档和练习怎么展开。

![学习方案确认和开始构建入口](/screenshots/build-plan.png)

_方案确认页的重点是章节顺序、知识点覆盖和资料是否纳入。确认无误后再点“开始构建”。_

确认前重点看：

- 章节顺序是否符合你的学习路径。
- 重点是否覆盖考试或任务目标。
- 资料是否被正确纳入。
- 练习安排是否太难或太浅。

如果方案不对，先反馈调整，不要急着开始构建。

## 方案不满意时怎么改

可以直接指出要调整的部分：

```text
章节太多了，压缩成 5 个模块，先覆盖高频考点。
```

```text
我基础比较弱，请把每一章都加上前置概念和例题。
```

```text
这门课主要为了考试，不要展开太多拓展阅读，优先安排练习和错因总结。
```

好的反馈通常包含：哪里不合适、希望改成什么、原因是什么。

## 构建会产出什么

| 产出 | 用途 |
| --- | --- |
| 知识文档 | 像讲义一样系统阅读 |
| 知识图谱 | 看知识点之间的关系 |
| 伴读问答 | 围绕课程内容追问 |
| 诊断练习 | 生成题目、判分和解释错因 |
| 学习画像 | 查看掌握度和复习建议 |

## 好课程的判断标准

一个好的课程通常具备：

- 目标明确。
- 资料边界清楚。
- 章节顺序可执行。
- 例题和练习能回到知识点。
- 后续对话能引用课程内容。

如果课程看起来像一篇泛泛摘要，通常是目标太宽、资料太杂或方案没有确认好。

## 推荐节奏

1. 先用 1-3 份核心资料生成课程。
2. 在方案页确认章节和重点。
3. 构建完成后先读知识文档，不急着刷题。
4. 遇到不懂的段落，回到课程对话追问。
5. 学完一章后再生成诊断练习。
