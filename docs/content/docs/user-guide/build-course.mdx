构建课程是 AITeachMe 的主路径。它会把你的目标和资料变成一个 Course，然后围绕这个 Course 生成后续学习资产。

## 一句话理解

构建课程不是“让 AI 回答一个问题”，而是创建一个可持续学习的空间。

这个空间里会沉淀：

- 资料和解析结果。
- 学习方案。
- 知识文档。
- 知识图谱。
- 对话、测验和学习画像。

## 写一个清楚的课程目标

推荐结构：

```text
我想学习/复习什么。我的基础如何。希望系统生成什么，以及有没有时间或考试范围限制。
```

示例：

```text
高数期末冲刺课，范围到定积分应用。我基础一般，三天后考试，希望按考点生成讲义、例题和练习。
```

## 确认学习方案

提交目标后，系统会先生成学习方案。这个步骤很重要，因为它决定后续文档和练习怎么展开。

确认前重点看：

- 章节顺序是否符合你的学习路径。
- 重点是否覆盖考试或任务目标。
- 资料是否被正确纳入。
- 练习安排是否太难或太浅。

如果方案不对，先反馈调整，不要急着开始构建。

## 构建会产出什么

| 产出 | 用途 |
| --- | --- |
| 知识文档 | 像讲义一样系统阅读 |
| 知识图谱 | 看知识点之间的关系 |
| 伴读问答 | 围绕课程内容追问 |
| 诊断练习 | 生成题目、判分和解释错因 |
| 学习画像 | 查看掌握度和复习建议 |

## 好课程的判断标准

一个好的课程通常具备：

- 目标明确。
- 资料边界清楚。
- 章节顺序可执行。
- 例题和练习能回到知识点。
- 后续对话能引用课程内容。

如果课程看起来像一篇泛泛摘要，通常是目标太宽、资料太杂或方案没有确认好。
