构建课程不是把一个问题交给聊天模型，而是生成知识文档、知识图谱和课程问答上下文，并为后续训练与课程画像提供基础。

## 目标至少包含三件事

<PromptExample>学习目的 + 内容范围 + 当前限制</PromptExample>

例如：

<PromptExample>
  我想用三天复习线性代数期末考试，范围到特征值与对角化；基础薄弱，请先补前置概念，每章安排一道典型例题。
</PromptExample>

“帮我学这个”没有说明取舍，容易得到覆盖过宽的方案。资料决定证据边界，目标决定系统如何组织这些资料。

## 开始构建前的检查顺序

1. **范围**：有没有漏掉必学内容，或混入明显超纲章节。
2. **顺序**：前置概念是否放在依赖它的章节之前。
3. **资料**：核心文件是否已纳入，失败文件是否被误选。
4. **难度**：解释、例题和练习是否符合当前基础。
5. **节奏**：章节数量是否能在你的时间内完成。

可以直接要求修改当前方案：

<PromptExample>
  把课程压缩成 5 个模块；先讲秩与方程组，再讲特征值；删除超出本次考试范围的二次型。
</PromptExample>

## 模型档位怎么选

| 档位 | 适合情况 |
| --- | --- |
| 自动 | 默认选择，由系统按任务自动选择 |
| 深度推理 | 资料复杂、课程结构或推导要求高 |
| 均衡 | 常规课程构建，速度与质量取中间值 |
| 快速 | 小型资料、快速验证流程 |

这三个手动档位分别对应设置中的推理、主文本和轻量模型；云端用户不需要自行配置具体模型。

## 构建中和构建完成

构建中可以查看阶段进度和草稿，但草稿不代表最终发布内容。完成后先打开知识库检查：

- 目录与确认方案是否一致。
- 公式、表格和代码块是否完整。
- 关键结论能否回到资料或正文依据。
- 知识图谱是否有可用节点。

<GuideCallout title="什么时候应该重建？" tone="warning">
  资料范围或课程结构根本错误时才重新构建。个别解释不清、互动图示不理想或需要补充例题时，优先在正文和课程问答中处理。
</GuideCallout>
