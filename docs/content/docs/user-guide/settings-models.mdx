设置页用于调整 AITeachMe 调用模型和检索资料的方式。普通学习流程不一定需要修改设置；只有在响应速度、生成质量或资料引用不符合预期时，才建议回来查看。

## 从哪里进入

点击左下角 **设置**，常用配置主要在这几个页面：

| 设置页 | 主要影响 |
| --- | --- |
| 模型接入 | 配置模型服务的连接方式 |
| 模型配置 | 选择主模型、推理模型、轻量模型、视觉模型和 Embedding 模型 |
| 学习引擎 | 影响课程构建和学习链路的部分策略 |
| 检索配置 | 影响资料问答和知识库检索效果 |

## 模型配置怎么看

常见模型槽位含义如下：

| 槽位 | 用在什么地方 |
| --- | --- |
| 主文本模型 | 日常生成、课程构建、对话和批改 |
| 推理模型 | 更复杂的规划、讲解和推理 |
| 轻量模型 | 分类、摘要和快速任务 |
| Embedding 模型 | 资料向量化、检索和课程问答 |
| 重排序模型 | 对检索结果进行再排序，可选 |

如果你不确定怎么选，保持默认即可。首页模型按钮里的“默认”会使用设置页中的主文本模型。

## 不要在文档里暴露什么

如果你要给别人截图或写教程，请遮掉这些内容：

- API Key、Token、Secret、Password。
- 数据库地址、对象存储密钥、私有网关地址。
- 真实手机号、邮箱、姓名和组织内部课程名。
- 私有资料文件名，尤其是带班级、姓名或项目代号的文件。

教程里可以使用这样的占位写法：

```text
LLM_API_KEY=<your-api-key>
LLM_BASE_URL=https://example.com/v1
```

不要把真实值直接粘贴进截图、课程说明或公开文档。

## 什么情况下需要调整

- 构建很慢：先检查所选模型档位，再看是否有模型调用超时。
- 回答没有引用资料：检查资料是否解析完成，再看检索配置。
- 知识图谱为空：确认课程构建和知识文档已经完成。
- 题目质量不稳定：优先缩小知识范围，再考虑更换更强的模型档位。

设置不是越复杂越好。先用默认配置跑通一门课，再根据具体问题调整。
