云端用户可调整：

- **界面主题**：浅色、深色或跟随系统。
- **显示具体分数**：开启后显示分数与题目对错；关闭后只显示完成状态。

云端的模型和检索能力由平台统一维护，普通用户不需要配置。

## 模型档位怎么选

首页课程构建、对话，以及知识文档内的互动 HTML 生成都使用同一套选择器：

| 页面档位 | 实际对应 | 适合场景 |
| --- | --- | --- |
| 自动 | 由系统按任务自动选择 | 大多数情况，不需要手动判断模型类型 |
| 深度推理 | 设置中的推理模型 | 复杂规划、深入讲解和推理 |
| 均衡 | 设置中的主文本模型 | 稳定生成、日常问答和课程内容 |
| 快速 | 设置中的轻量模型 | 轻量问答、标题、分类和快速生成 |

“自动”不是第四个具体模型，而是让系统按任务选择。手动选择档位后，本次课程构建、对话或互动 HTML 生成会使用对应类型的模型；互动 HTML 里的“生成”和“按要求生成”也遵循同一映射。

## 本地模式会多出什么

本地模式会额外显示模型与检索选项。只有在模型无法使用、响应速度不合适或资料检索没有结果时，才需要回来调整。

- **生成模型**影响课程、问答和互动内容的速度与质量。
- **向量模型**只影响系统怎样从资料里找到相关片段。

## 向量模型到底做什么

向量模型用于查找与当前问题最相关的资料片段。它不负责写正文，也不等同于“深度推理”“均衡”或“快速”这三个生成档位。

看到向量模型或检索索引提示时，通常表示这门课程的资料检索还没有准备好，或者本地更换设置后需要重新整理索引。课程正文和已上传资料不会因此丢失。

- **云端**：先刷新并重试；提示持续出现时再反馈给平台。
- **本地模式**：课程构建确认弹窗出现冲突提示时，可选择全量重建语义索引，或继续构建并关闭当前课程的语义检索。

## 按现象快速判断

| 现象 | 先检查 |
| --- | --- |
| 生成质量不够 | 缩小任务范围，或改用“深度推理” |
| 课程构建太慢 | 改用“均衡”或“快速” |
| 问答没有命中资料 | 文件是否解析完成，页面是否有向量检索提示 |
| 图谱为空 | 知识文档是否发布、图谱同步是否完成 |
| 互动 HTML 生成失败 | 重试一次，再切换“均衡”或“深度推理” |

本地模式每次只改一项，再用短资料或小任务验证，方便判断哪项设置真正产生了影响。
