训练中心不是只有一种“刷题”。AITeachMe 目前把训练分成三类：**测验**、**考卷** 和 **闯关**。它们都围绕当前课程资料和题库，但节奏不同。

![训练中心测验入口](/screenshots/exams-overview.png)

_训练中心会把训练模式和历史记录放在同一个页面，方便你继续未完成内容或回看错因。_

## 三种模式怎么选

| 模式 | 适合什么时候 | 题目节奏 |
| --- | --- | --- |
| 测验 | 日常复习、阶段摸底、快速找薄弱点 | 题量较小，适合 10-15 分钟完成 |
| 考卷 | 阶段检测、考前模拟、想练完整卷面 | 按完整试卷组织题型，时间更长 |
| 闯关 | 已经有题库沉淀，想反复巩固错题和薄弱点 | 一页一题，答完立刻看反馈 |

如果你是第一次使用，建议先从 **测验** 开始。它更短，也更容易判断系统有没有抓住当前章节重点。

## 测验：快速诊断

测验适合用来问：“我这一章到底哪里不会？”

推荐请求：

```text
围绕本章核心概念生成 8 道测验题，先考基础定义，再考两个应用场景。
```

测验完成后先看错因，不要只看分数。错因里如果出现某个知识点反复出错，再回到知识图谱或知识文档复习。

## 考卷：完整模拟

考卷会按更完整的卷面组织题型，更适合阶段测试和考前模拟。创建考卷时可以设置题量、难度、重点范围，也可以选择卷面格式。

![创建测验参数设置](/screenshots/create-exam-settings.png)

目前考卷格式包括：

| 格式 | 适合场景 |
| --- | --- |
| 自动匹配 | 不想手动选，让系统按题量决定页面结构 |
| 一面两页 | 常规测试或较短试卷 |
| 高考四页 | 模拟较短的折页试卷 |
| 高考六页 | 模拟中等长度的折页试卷 |
| 高考八页 | 模拟更长的整卷 |

如果只是日常复习，不必一开始就用考卷。等你学完一组章节后，再用考卷做一次更完整的检验。

## 闯关：薄弱点专项巩固

闯关更像短回合训练：一页一题，作答后立刻看结果。它优先复用课程题库；如果题库题目不足，系统会尝试自动准备新题，并在后续沉淀到题库。

![薄弱点专项练习](/screenshots/mastery-drill.png)

适合这样用：

```text
我刚做完测验，想把错题相关的知识点再闯关巩固一遍。
```

闯关不适合替代完整考试模拟。它更适合把已经暴露出来的薄弱点补牢。

## 做题后怎么复盘

![测验作答与复盘入口](/screenshots/exam-detail.png)

复盘时建议按这个顺序看：

1. 先看错题和错因。
2. 再看题目关联的知识点。
3. 回到知识文档或图谱补概念。
4. 最后再生成一组变式题。

## 和学习画像的关系

测验、考卷和闯关都会为学习画像提供信号。刚开始题量少时，画像可能只是粗略判断；完成几轮训练后，掌握度和薄弱点会更有参考价值。

![学习画像总览](/screenshots/profile-overview.png)

如果你不知道下一步选哪种模式，可以按这个顺序：

```text
测验找薄弱点 -> 闯关补薄弱点 -> 考卷做阶段模拟 -> 回到画像看下一轮建议
```
