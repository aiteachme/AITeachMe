训练中心把三种用途不同的训练放在同一页：短测用于定位问题，考卷用于完整模拟，闯关用于围绕题库和薄弱点连续练习。

## 怎么选

| 模式 | 最适合回答的问题 | 推荐起点 |
| --- | --- | --- |
| 测验 | 我刚学完这一章，哪里还没理解？ | 5–10 题，单章或少量知识点 |
| 考卷 | 完整范围下，我能否在规定时间完成？ | 学完一组章节后再生成 |
| 闯关 | 已知薄弱点后，能否通过连续反馈补牢？ | 从题库和错题关联知识点开始 |

第一次训练优先使用测验。范围太大、题量太多时，很难判断题目质量和真正的错因。

## 生成前校对四项

- 知识范围是否与当前学习进度一致。
- 题型是否适合目标，不能只靠选择题判断推导能力。
- 难度是否有层次，而不是所有题都卡在同一步。
- 题量是否能在当前时间内认真复核。

## 生成后先抽查，再正式作答

随机看几道题，确认：

1. 条件完整，没有缺图、缺单位或符号混乱。
2. 题目确实来自所选知识范围。
3. 选择题有明确唯一答案，多选题规则清楚。
4. 标准答案和题解能由题目条件推出。

发现系统性问题时，停止作答并缩小范围重新生成。不要为了保留一次训练记录而接受明显错误的题目。

## 做完之后

按 **答题 → 讲评 → 复习** 三步走。讲评页逐题核对，复习页把错误合并成学习指南，最后再到课程画像看一段时间内的变化。

<GuideCallout title="不要只看总分" tone="success">
  两个相同分数可能来自完全不同的问题：概念不清、公式选错、计算失误或审题偏差。下一轮训练应针对错因，而不是简单增加题量。
</GuideCallout>
