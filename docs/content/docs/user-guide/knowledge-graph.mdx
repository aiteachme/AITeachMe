知识图谱不是另一份课程目录。它把概念、原理、公式、方法、技能、易错点和应用连接起来，适合回答“这个知识依赖什么”和“我下一步该补哪里”。

## 第一次打开只做三件事

1. 找到正在阅读的章节或概念。
2. 查看它直接相连的前置和应用节点。
3. 打开节点详情，核对解释和来源。

不要试图一次看完整张图。节点很多时，先筛选当前章节或搜索具体概念，再沿一层关系展开。

## 节点颜色和类型

图谱会区分主题、核心概念、原理、公式模型、方法步骤、解题技能、易错辨析和应用案例。类型用来帮助浏览，不代表掌握度高低；真正的薄弱点需要结合训练记录和课程画像判断。

## 什么时候从图谱跳回正文

- 节点解释过短，需要完整定义和推导。
- 两个概念连在一起，但不清楚关系成立的条件。
- 来源片段与当前理解不一致。
- 准备做题，需要先复习对应例题或方法。

## 图谱为空或出现构建提示

先检查知识文档是否已经正式发布。课程构建刚完成时，图谱同步可能仍在收尾；刷新后仍为空，再查看构建状态。

出现向量检索提示时，不代表课程正文丢失。向量模型只负责查找相关资料；按页面操作修复或重建即可，云端用户通常不需要手动处理。

<GuideCallout title="图谱关系也要核对">
  高连接度不等于高重要度，自动提取的关系也可能过宽。遇到关键依赖关系时，回到来源和知识文档确认，再把它用于复习或出题。
</GuideCallout>
