---
title: 知识图谱
description: 用图谱查看知识点关系、来源和复习路径。
---

知识图谱适合在课程已经构建后使用。它不是另一份长文档，而是把课程里的知识点、章节和依赖关系连起来，帮助你判断“这个概念为什么在这里出现”和“下一步该补哪一块”。

![知识文档、知识图谱和伴读问答动图](/guides/knowledge-loop-guide.gif)

_推荐顺序是：先读知识文档，再用图谱看关系，最后把卡住的节点带进伴读问答。_

## 什么时候看图谱

| 场景 | 看图谱能帮你什么 |
| --- | --- |
| 读完一章但不知道重点 | 看这一章关联了哪些核心知识点 |
| 概念之间容易混 | 看相邻节点和来源片段，找到它们的差异 |
| 想查漏补缺 | 从薄弱知识点向前看前置概念，向后看应用题 |
| 准备测验 | 先看高连接度节点，再生成一组小测 |

## 从哪里打开

1. 进入某门课程。
2. 打开左侧或顶部的 **知识库**。
3. 在知识库页面右侧点击 **知识图谱**。
4. 如果图谱还没有生成，点击 **构建图谱** 或等待课程构建流程完成。

知识图谱通常会跟随知识文档一起构建。资料刚上传完时，先等知识文档和图谱状态变成可用，再用它做复习导航。

## 图谱里主要看什么

| 元素 | 含义 |
| --- | --- |
| 节点 | 一个知识点、概念、公式、方法或章节主题 |
| 连线 | 知识点之间的依赖、包含、应用或对比关系 |
| 来源 | 这个节点来自哪些课程资料或知识文档片段 |
| 详情面板 | 当前知识点的解释、相关节点和可跳转来源 |

第一次不要试图把整张图看完。更好的方式是从正在学的章节或一个薄弱点开始，只看它附近的一小圈关系。

## 推荐用法

### 1. 先从章节出发

读完某一章后，打开图谱，找到这一章对应的核心节点。先看直接相连的概念，再回到知识文档复习解释。

### 2. 用来源确认系统读到了什么

如果你担心图谱里的知识点不准确，打开节点详情里的来源。来源能帮助你判断它来自哪份资料、哪个知识文档片段。

### 3. 把图谱和训练中心连起来

图谱不是只用来看的。你可以先找出几个高频或薄弱节点，再去训练中心生成一组小测：

```text
围绕这几个知识点生成 8 道测验题，先考基础定义，再考典型应用。
```

### 4. 用图谱辅助伴读问答

当你问 AI 一个概念时，可以顺带说明它和哪个节点或章节有关：

```text
我在知识图谱里看到 A 和 B 有关联，但我分不清它们在题目里的区别。请用例题解释。
```

## 如果图谱为空或不完整

| 现象 | 先检查 |
| --- | --- |
| 暂无图谱数据 | 课程是否已经开始构建知识库 |
| 只有少量节点 | 资料是否解析完成，知识文档是否已发布 |
| 图谱构建失败 | 点击知识图谱面板里的重新构建，或查看课程构建状态 |
| 问答没有引用图谱 | 当前是否在课程内提问，资料和图谱是否已就绪 |

知识图谱的目标是帮你定位路径，不是替代正文学习。遇到细节问题，仍然回到知识文档、资料来源和伴读问答里确认。
