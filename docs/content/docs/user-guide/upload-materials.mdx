资料越多不一定越好。第一次构建课程时，优先选择能说明 **范围、核心内容和题型** 的 1–3 份文件，例如课程大纲、主讲义和一份练习或错题。

## 哪些资料适合直接上传

| 资料 | 建议 |
| --- | --- |
| PDF、Word、PPT、Markdown、TXT | 适合，优先使用文字层清楚的版本 |
| 扫描讲义、图片题目 | 可以，但要抽查 OCR、公式和表格 |
| 整本教材 | 先截取当前学习范围，避免课程边界过大 |
| 答案、错题和题库 | 与对应章节资料一起上传，避免只生成刷题课 |

文件名最好能看出内容，例如 `线性代数-第三章-向量组.pdf`。大量 `未命名.pdf` 会让后续选资料和排错变得困难。

## 三种状态怎么处理

| 状态 | 现在该做什么 |
| --- | --- |
| 解析中 | 等待完成，不要反复上传同一文件 |
| 已解析 | 可以加入课程；扫描件和复杂公式仍建议抽查 |
| 失败 | 打开文件确认格式和内容，必要时转换或拆分后重传 |

<GuideSteps>
  <GuideStep number={1} title="从首页上传或打开资料库">
    新文件点击“上传资料”；已经上传过的文件直接从资料库选择，不必重复上传。
  </GuideStep>
  <GuideStep number={2} title="等待解析结果">
    文件进入“已解析”后再用于正式构建。较长扫描件需要更多时间。
  </GuideStep>
  <GuideStep number={3} title="回到首页确认已选数量">
    检查输入区显示的资料数量和文件名，再提交课程目标。
  </GuideStep>
</GuideSteps>

## 怎么判断系统确实读到了资料

- 资料库状态为“已解析”。
- 课程方案出现与资料一致的章节、概念或题型。
- 课程问答能指出相关正文或来源，而不是泛泛回答。
- 生成题目的范围没有越过你选择的资料和目标。

如果方案与资料明显无关，先确认是否选错文件、文件是否只有扫描图，或目标是否过于宽泛。

<GuideCallout title="涉及隐私的资料">
  上传前删除账号密码、身份证件、真实联系方式、内部密钥和无关个人信息。课程分享或导出前，还要检查文件名和课程说明是否泄露内部项目名称。
</GuideCallout>
