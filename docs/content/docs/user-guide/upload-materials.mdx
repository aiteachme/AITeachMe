资料是 AITeachMe 构建课程的起点。上传越清晰，后续知识文档、伴读问答和测验越稳定。

## 可以上传什么

优先上传这些资料：

- 教材章节、课程讲义、课堂 PPT。
- 题库、答案、错题本、复习提纲。
- Markdown、TXT 或已经整理过的笔记。

不太适合作为首批资料的内容：

- 排版极乱、扫描质量很差的整本书。
- 没有文字层且 OCR 配置不可用的图片。
- 与课程主题无关的大量杂项文件。

## 上传后看哪里

![资料库文件选择和就绪状态](/screenshots/library-picker.png)

_资料库会显示文件类型、大小和状态。截图中的具体资料名已做脱敏；实际使用时请选择状态为“已就绪”的资料。_

用户通常只需要关心三个状态：

| 状态 | 含义 |
| --- | --- |
| 解析中 | 文件已经上传，系统正在提取文本和资源 |
| 已就绪 | 文件可用于构建课程和问答 |
| 失败 | 文件无法解析或解析器返回错误 |

已就绪不代表内容一定完美。扫描件、复杂公式、图片表格仍可能需要人工核对。

## 上传前检查清单

上传前可以先快速看一眼：

- 文件名是否能看出主题，避免全是 `未命名`、`新建文档`。
- 文件内容是否和这门课直接相关。
- 扫描件是否清晰，公式和表格是否能被看清。
- 一次不要混入太多无关资料，先用核心资料跑通。

## 上传资料和资料库的区别

| 操作 | 适合场景 |
| --- | --- |
| 上传资料 | 把新文件加入系统，适合第一次使用或补充新讲义 |
| 选资料 | 从已有资料库中选择文件，加入这次课程构建 |

如果你已经上传过同一份讲义，不必重复上传，直接从资料库选择即可。

## 首次上传怎么点

1. 在首页输入框或对话框下方点击“上传资料”。
2. 从本机选择文件。
3. 等待上传完成，系统会进入解析。
4. 回到资料库查看状态。
5. 状态变为“已就绪”后，再把这份资料加入课程或对话。

如果状态长时间停在“解析中”，先换一份更短、更清晰的资料验证流程。

## 从资料库选择怎么点

1. 点击“选资料”或“资料库”。
2. 在弹窗里勾选需要加入当前课程的资料。
3. 优先选择状态为“已就绪”的资料。
4. 点击“确认选择”。
5. 回到输入框，确认已选择资料数量正确。
6. 再发送课程目标或问题。

如果你在对话里上传了资料，但回答没有使用它，先确认输入框里是否还显示已选资料，或者切回课程内再问。

## 资料如何影响课程

构建课程时，资料会影响：

- 章节边界。
- 重点概念。
- 例题和练习的来源。
- 伴读问答能否引用课程内容。

但资料不会自动替你决定学习目标。你仍然需要告诉系统这门课面向什么考试、什么水平、什么时间限制。

## 怎么判断 AI 读到了资料

可以从这些信号判断：

- 输入框或对话中能看到已选择的资料数量。
- 资料库状态已经从“解析中”变成“已就绪”。
- 课程方案里出现了和资料章节一致的主题。
- 课程内问答能引用资料里的概念、章节或题型。

如果回答明显像泛泛而谈，先检查当前对话是否在课程内、资料是否已就绪，以及提问里是否明确说“结合我选中的资料”。

## 推荐资料组合

| 目标 | 推荐资料 |
| --- | --- |
| 生成一门冲刺课 | 课程大纲、核心讲义、近几次练习或题库 |
| 补某一章基础 | 对应章节讲义、一小组例题、自己的错题 |
| 做考前诊断 | 复习范围说明、样题、错题或模拟题 |
| 解释复杂概念 | 相关课件、教材片段、自己的疑问记录 |

## 常见问题

### 上传了资料，为什么还要写目标？

同一份资料可以生成不同课程。比如高数资料可以生成“期末冲刺课”“概念补课”“错题训练课”。目标决定系统如何取舍。

### 资料解析失败怎么办？

先换一个更短、更清晰的文件验证链路。如果只有扫描图，确认图片文字识别或文档解析能力是否可用。

### 资料很多时怎么上传？

先上传最核心的 1-3 份资料，跑通课程后再补。一次性上传太多低质量资料会让课程边界变模糊。
