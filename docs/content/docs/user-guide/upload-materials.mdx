资料是 AITeachMe 构建课程的起点。上传越清晰，后续知识文档、伴读问答和测验越稳定。

## 可以上传什么

优先上传这些资料：

- 教材章节、课程讲义、课堂 PPT。
- 题库、答案、错题本、复习提纲。
- Markdown、TXT 或已经整理过的笔记。

不太适合作为首批资料的内容：

- 排版极乱、扫描质量很差的整本书。
- 没有文字层且 OCR 配置不可用的图片。
- 与课程主题无关的大量杂项文件。

## 上传后发生什么

上传后，系统会把原始文件变成后续流程可消费的内容。用户通常只需要关心三个状态：

| 状态 | 含义 |
| --- | --- |
| 解析中 | 文件已经上传，系统正在提取文本和资源 |
| 已就绪 | 文件可用于构建课程和问答 |
| 失败 | 文件无法解析或解析器返回错误 |

已就绪不代表内容一定完美。扫描件、复杂公式、图片表格仍可能需要人工核对。

## 上传资料和资料库的区别

- 上传资料：把新文件加入系统。
- 选资料：从已有资料库中选择文件，加入这次课程构建。

如果你已经上传过同一份讲义，不必重复上传，直接从资料库选择即可。

## 资料如何影响课程

构建课程时，资料会影响：

- 章节边界。
- 重点概念。
- 例题和练习的来源。
- 伴读问答能否引用课程内容。

但资料不会自动替你决定学习目标。你仍然需要告诉系统这门课面向什么考试、什么水平、什么时间限制。

## 常见问题

### 上传了资料，为什么还要写目标？

同一份资料可以生成不同课程。比如高数资料可以生成“期末冲刺课”“概念补课”“错题训练课”。目标决定系统如何取舍。

### 资料解析失败怎么办？

先换一个更短、更清晰的文件验证链路。如果只有扫描图，检查 OCR 或文档解析配置。开发环境可以查看后端日志定位失败原因。

### 资料很多时怎么上传？

先上传最核心的 1-3 份资料，跑通课程后再补。一次性上传太多低质量资料会让课程边界变模糊。
