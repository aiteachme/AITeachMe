## 先用目录判断课程是否靠谱

正式阅读前，用半分钟扫一遍左侧目录：

- 章节顺序是否与确认过的方案一致。
- 核心概念是否有单独的小节，而不是挤在一段总结里。
- 是否出现明显超出资料或学习目标的内容。
- 公式、例题和方法是否落在对应章节下。

目录边界明显不对时，优先回到 **方案规划** 检查课程目标和构建记录。不要靠后续问答去弥补一份方向错误的正文。

## 一章的推荐读法

<GuideSteps>
  <GuideStep number={1} title="先看章节目标和结构">
    确认这一章解决什么问题，以及它依赖哪些前置概念。不要一开始就盯着例题答案。
  </GuideStep>
  <GuideStep number={2} title="遇到断点就原地追问">
    划选看不懂的定义、公式或步骤，再打开 AI 交互窗口。问题会保留当前课程和正文位置的上下文。
  </GuideStep>
  <GuideStep number={3} title="用图谱核对关系">
    对概念之间的前置、包含或应用关系不确定时，打开知识图谱，只看当前节点附近的关系。
  </GuideStep>
  <GuideStep number={4} title="读完再做一组短测">
    先用少量题验证理解。题目和题解不可信时先复核，不要让错误结论继续进入复习记录。
  </GuideStep>
</GuideSteps>

## 正文太窄或目录挡住内容

点击右侧 **宽页模式** 可以扩大正文区域。长表格、代码和多列公式更适合宽页阅读；需要频繁跳章节时再切回目录布局。

阅读位置会按课程保存。再次打开页面时，内容加载完成后会回到上次阅读处。

## 互动 HTML 和可视化内容

部分课程会在构建阶段规划互动内容；首次展开对应内容时，系统再生成互动 HTML，用来解释图形、过程或可操作示例。它是知识文档的补充，不应替代正文中的定义、推导和来源依据。

生成结果出现空白、布局溢出或内容与正文矛盾时，以课程资料和正文为准，并重新生成或关闭该互动内容。互动 HTML 和课程构建使用同一套模型档位：“深度推理”“均衡”“快速”分别对应设置中的推理、主文本和轻量模型，“自动”则由系统按任务选择。

<GuideCallout title="为什么会看到向量模型提示？" tone="warning">
  向量模型只负责从资料中查找相关片段，不负责生成正文。看到提示时按页面操作修复或重建检索；云端通常不需要手动处理。
</GuideCallout>

## 怎么判断这一章可以进入训练

- 你能用自己的话说明本章核心概念。
- 关键公式知道适用条件，而不是只会代数值。
- 能指出至少一个容易混淆或出错的地方。
- 能在图谱或正文中找到依据。

满足这些条件后，去训练中心做一组小测比继续被动阅读更有效。
