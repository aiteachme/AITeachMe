分数只是结果，复核才决定这次训练是否能形成可靠的学习记录。AITeachMe 会生成讲评、错因、复习指南和课程画像，但 AI 生成的题目与题解仍然需要校对，尤其是公式推导、边界条件和多解问题。

## 做完题先检查什么

进入课程的 **训练中心**，在 **训练记录** 中展开 **已完成**，再打开对应的测验或考卷。进入讲评后展开具体题目，不要只停留在总分和整体建议。

按这个顺序复核：

1. **题目是否成立**：条件是否完整，符号和单位是否一致，有没有多种合理解释。
2. **标准答案是否正确**：选择项、数值和结论能否由题目条件推出。
3. **题解过程是否闭合**：每一步是否有依据，是否偷换条件、漏解或把充分条件当成必要条件。
4. **判分是否匹配作答**：主观题要看你的关键步骤是否被识别，不只看最终字符串。
5. **知识点映射是否合理**：错题应回到真正导致错误的知识点，而不是只按题目标题归类。

<GuideCallout title="题解可疑时先停下来" tone="warning">
  对照课程资料重新推一遍，或在课程问答中要求 AI 列出每一步依据和适用条件。没有确认正确前，不要把这道题当成复习标准答案，也不要只根据本题分数判断掌握度。
</GuideCallout>

## 讲评、复习指南和画像各看什么

| 页面 | 回答的问题 | 重点检查 |
| --- | --- | --- |
| 讲评 | 这道题为什么对或错 | 标准答案、步骤、错因和知识点是否一致 |
| 复习指南 | 这次训练之后先补什么 | 是否真正针对反复出现的薄弱点 |
| 课程画像 | 一段时间内哪里更稳定或更薄弱 | 样本数量、最近表现和建议是否匹配 |

画像中最值得关注的不是一个总分，而是：

- 哪些知识点连续多次出错。
- 错误发生在概念、方法、计算还是审题。
- 哪些知识点已经很久没有复习。
- 推荐任务是否对应你当前的考试或学习范围。

## 一次可靠的复盘闭环

1. 完成作答后，先校对题目、标准答案和题解。
2. 确认真正的错因及其对应知识点。
3. 阅读复习指南，只处理最优先的薄弱点。
4. 回到知识文档或伴读问答补齐理解断点。
5. 用少量变式题验证，而不是立刻扩大刷题量。
6. 积累新的真实作答后，再看画像是否发生变化。

如果一组题本身质量不稳定，应先停止扩大量级。修正知识范围或重新生成，比继续刷同一批有问题的题更重要。
