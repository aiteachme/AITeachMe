用户教程按照真实学习路径组织：先把资料放进来，再构建课程，之后围绕课程继续提问、练习和查看掌握度。

## 推荐阅读顺序

| 阶段 | 文档 |
| --- | --- |
| 准备资料 | [上传资料](/docs/user-guide/upload-materials) |
| 生成课程 | [构建课程](/docs/user-guide/build-course) |
| 追问和解释 | [伴读问答](/docs/user-guide/chat) |
| 检查掌握度 | [测验和画像](/docs/user-guide/exams-profile) |

## 学习闭环

```text
上传资料 -> 构建课程 -> 伴读问答 -> 诊断测验 -> 学习画像
```

## 页面入口对照

| 页面里看到的入口 | 主要做什么 |
| --- | --- |
| 知识库 | 看知识文档、知识图谱，围绕课程内容继续追问 |
| 训练中心 | 生成题目、测验或考卷，查看错因 |
| 课程画像 | 看掌握度、薄弱点和复习建议 |
| 全局对话 | 还没进入某门课时，先咨询、解释资料或澄清目标 |

## 什么时候回来查这组文档

- 上传资料后，不确定系统是否已经读到内容。
- 首页输入框不知道应该写课程目标还是普通问题。
- 课程已经生成，但不知道知识文档、对话和测验之间怎么配合。
- 想理解画像里的掌握度和薄弱点从哪里来。

## 最小使用套路

```text
先说清目标
  -> 只选最相关的资料
  -> 确认学习方案
  -> 读一章
  -> 问一个具体问题
  -> 做一组诊断题
  -> 根据画像补薄弱点
```

如果中间任何一步结果不对，优先回到上一环节补充信息：目标太宽就缩小目标，资料太杂就减少资料，方案不合适就先调整方案。

如果你是第一次使用，建议先从 [跑通第一门课](/docs/quickstart/first-course) 开始。
