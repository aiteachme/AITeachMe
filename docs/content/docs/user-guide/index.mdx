用户教程按照真实学习路径组织：先把资料放进来，再构建课程，之后围绕课程继续提问、练习和查看掌握度。

## 推荐阅读顺序

| 阶段 | 文档 |
| --- | --- |
| 准备资料 | [上传资料](/docs/user-guide/upload-materials) |
| 生成课程 | [构建课程](/docs/user-guide/build-course) |
| 追问和解释 | [自由对话](/docs/user-guide/chat) |
| 检查掌握度 | [测验与画像](/docs/user-guide/exams-profile) |

## 什么时候回来查这组文档

- 上传资料后，不确定系统是否已经读到内容。
- 首页输入框不知道应该写课程目标还是普通问题。
- 课程已经生成，但不知道知识文档、对话和测验之间怎么配合。
- 想理解画像里的掌握度和薄弱点从哪里来。

如果你是第一次使用，建议先从 [跑通第一门课](/docs/quickstart/first-course) 开始。
