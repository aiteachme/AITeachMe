AITeachMe 的测验和学习画像服务同一个目标：让你知道自己到底哪里会、哪里不会、下一步该补什么。

## 诊断练习解决什么

诊断练习适合：

- 考前检查薄弱点。
- 针对某个章节生成题目。
- 用错因解释替代只看答案。
- 根据课程资料生成更贴近当前学习内容的题。

测验不是题库随机抽题。更理想的路径是：先有课程资料和知识文档，再根据课程内容生成练习。

## 做完题后看什么

不要只看分数。更重要的是：

- 错在哪个知识点。
- 错因是概念不清、公式不会用，还是题目变形没识别。
- 是否需要回到知识文档复习。
- 是否需要再生成一组相似题。

## 学习画像是什么

学习画像会把测验、对话和课程进度沉淀成更稳定的学习信号。MVP 阶段重点是历史统计和掌握度展示。

你可以把它理解成：

```text
每个知识点的掌握度 + 最近表现 + 复习建议
```

## 什么时候画像更可信

画像需要学习行为积累。刚创建课程时，它可能只能提供粗略判断；当你完成更多测验和复盘后，掌握度会更有参考价值。

## 推荐使用方式

1. 先构建课程并阅读知识文档。
2. 针对章节生成一组诊断题。
3. 做完后查看错因和薄弱点。
4. 回到知识文档或伴读问答补概念。
5. 再生成一组变式题验证。

这样比直接刷大量题更容易形成闭环。
