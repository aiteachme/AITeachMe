AITeachMe 的测验和学习画像服务同一个目标：让你知道自己到底哪里会、哪里不会、下一步该补什么。

## 推荐闭环

```text
读知识文档 -> 生成诊断题 -> 看错因 -> 回到薄弱知识点 -> 再练一组
```

## 诊断练习解决什么

诊断练习适合：

- 考前检查薄弱点。
- 针对某个章节生成题目。
- 用错因解释替代只看答案。
- 根据课程资料生成更贴近当前学习内容的题。

测验不是题库随机抽题。更理想的路径是：先有课程资料和知识文档，再根据课程内容生成练习。

## 可以怎么生成题

```text
根据这门课的前三个知识点，生成 5 道选择题和 2 道简答题，难度从基础到中等。
```

```text
只针对我刚才答错的知识点，再出一组变式题，并在最后解释每题考什么。
```

```text
帮我做一次考前诊断，不要题量太大，先覆盖最容易混淆的概念。
```

创建测验时，优先先选知识范围、题量和难度。第一次不要把题量拉太大，先用一组小题确认系统是否抓住了你的薄弱点。

## 做完题后看什么

不要只看分数。更重要的是：

- 错在哪个知识点。
- 错因是概念不清、公式不会用，还是题目变形没识别。
- 是否需要回到知识文档复习。
- 是否需要再生成一组相似题。

![测验详情与答题反馈](/screenshots/exam-detail.png)

_详情页更适合做复盘：先看错因，再回到对应知识点，不要只盯总分。_

## 学习画像是什么

学习画像会把测验、对话和课程进度沉淀成更稳定的学习信号。

你可以把它理解成：

```text
每个知识点的掌握度 + 最近表现 + 复习建议
```

## 什么时候画像更可信

画像需要学习行为积累。刚创建课程时，它可能只能提供粗略判断；当你完成更多测验和复盘后，掌握度会更有参考价值。

![学习建议和复习入口](/screenshots/study-guide.png)

_学习建议会更适合在完成几轮学习和测验后查看。它不是一次性结论，而是下一轮复习的导航。_

## 推荐使用方式

1. 先构建课程并阅读知识文档。
2. 针对章节生成一组诊断题。
3. 做完后查看错因和薄弱点。
4. 回到知识文档或伴读问答补概念。
5. 再生成一组变式题验证。

这样比直接刷大量题更容易形成闭环。

![薄弱点专项练习](/screenshots/mastery-drill.png)

_当画像指出薄弱点后，再生成一组专项练习，比盲目刷题更容易补到关键处。_

## 一周复习建议

如果你只有一周，可以这样安排：

| 时间 | 建议动作 |
| --- | --- |
| 第 1 天 | 构建课程，确认章节和重点 |
| 第 2-3 天 | 阅读知识文档，遇到不懂的地方用伴读问答补概念 |
| 第 4 天 | 做第一组诊断题，整理错因 |
| 第 5-6 天 | 针对薄弱点生成变式题 |
| 第 7 天 | 看学习画像和错题，做最后一轮查漏补缺 |

画像不是为了给你贴标签，而是帮你决定下一轮学习先补哪里。
