title: 伴读问答
description: 理解自由对话、课程对话和资料问答的关系。
---

AITeachMe 的对话不是只为了给最终答案。更理想的方式是围绕课程资料和学习状态，帮助你理解、复盘和继续学习。

## 两种常见对话

![全页自由对话界面](/screenshots/assistant-chat.png)

_全局对话会以完整页面展示，适合连续澄清目标、临时问答，或者先把资料放进来一起分析。_

| 对话类型 | 适合场景 |
| --- | --- |
| 全局对话 | 还没有明确课程，想先咨询、澄清目标或临时问答 |
| 课程对话 | 已经有课程资料、知识文档或测验记录，想围绕当前课程追问 |

如果你希望 AI 结合课程内容回答，优先在课程内提问。

## 可以怎么问

好的问题通常带有上下文：

```text
我看不懂二次函数图像和解析式之间的关系，能用一道题一步步讲吗？
```

```text
结合这门课的资料，帮我总结操作系统进程和线程的区别，并出 3 道判断题。
```

```text
我刚才这道题为什么错？请先指出知识点，再给我一个类似变式。
```

## 带资料提问模板

如果希望回答严格结合资料，可以这样写：

```text
结合我选中的资料，先指出这一章最核心的 3 个概念，再说明它们之间的关系。
```

```text
只根据这门课已经生成的知识文档回答：这个公式什么时候能用，什么时候不能用？
```

```text
请从资料里找出和这道题相关的知识点，先不要直接给答案，先一步步提示我。
```

如果你不确定资料是否已经进入上下文，可以先问：

```text
你现在能看到哪些课程资料？请先按资料来源列出来，再回答我的问题。
```

## 资料引用和可信度

当课程资料或知识文档可用时，回答可以带来源或片段。你可以用这些信号判断回答是否来自课程内容。

如果回答没有引用，可能是：

- 当前不在这门课里提问。
- 课程还没有生成知识文档。
- 资料还没有准备好。
- 问题太泛，系统没有命中合适片段。

## 回答不理想时怎么追问

| 问题 | 可以怎么追问 |
| --- | --- |
| 回答太泛 | “请只围绕这门课的资料回答，并列出依据。” |
| 直接给答案 | “不要直接给最终答案，先用提示引导我。” |
| 难度太高 | “假设我基础薄弱，用更基础的例子重讲一遍。” |
| 没有练习 | “围绕刚才解释的知识点，出 3 道递进题。” |
| 没有定位错因 | “请把我的错误分成概念、公式、审题或计算问题。” |

## 对话不是替代确认

全局对话可以帮助你澄清学习目标，但不会自动跳过课程构建的方案确认。这样做是为了避免把一次聊天误当成正式课程生成。

当你已经准备好构建课程，可以把对话中确认过的目标整理成一句话，再进入“构建课程”模式。
