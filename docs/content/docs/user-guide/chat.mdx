---

AITeachMe 有三种常见问答入口。它们看起来都像对话框，但能使用的上下文不同。

| 入口 | 适合什么问题 | 默认上下文 |
| --- | --- | --- |
| 全局对话 | 目标还不清楚、临时咨询、比较几种学习路径 | 当前对话与主动选择的资料 |
| 课程对话 | 围绕整门课程追问、整理章节、联系错题 | 当前课程、知识文档和学习记录 |
| 正文划选问答 | 某句话、公式或步骤看不懂 | 当前课程、选中文本和所在章节 |

希望回答结合课程资料时，优先使用课程对话或划选问答。

## 问题要包含什么

比起“讲一下这个”，下面这种问法更容易得到可检查的回答：

<PromptExample>
  结合当前章节，解释为什么向量组的秩小于向量个数时一定线性相关。先说明判定链条，再给一个 3 个向量的反例对比；不要直接省略行变换步骤。
</PromptExample>

一个可执行的问题通常包含：

- 当前不懂的具体结论或步骤。
- 希望使用的课程范围或资料。
- 需要解释、提示、对比还是变式题。
- 是否暂时不要给最终答案。

## 回答没有依据时

1. 确认当前是否在正确课程中。
2. 确认知识文档已经发布、资料已经解析。
3. 缩小问题到一个章节或概念。
4. 要求回答列出正文位置、来源或适用条件。

引用来源只能说明回答使用了哪段上下文，不能自动证明结论正确。涉及公式、定义边界和题目答案时仍要回到资料核对。

## 用苏格拉底式提示而不是直接抄答案

<PromptExample>
  先不要给最终答案。请判断我卡在定义、公式选择还是计算，并且每次只给一个提示。
</PromptExample>

<PromptExample>
  我先说自己的推理，你只指出第一处不成立的地方，再问我一个能继续推导的问题。
</PromptExample>

这种问法更适合真正形成理解，也能让后续错因记录更准确。
