导入课程适合在你已经有课程包、团队共享课程，或者只想先体验 AITeachMe 时使用。

## 一句话理解

新建课程是从你的目标和资料开始生成；导入课程是复用已经准备好的课程内容。

## 从哪里进入

- 首页左侧的 **导入课程**。
- 首页下方的 **精选演示课程包**。
- 团队或同学发给你的课程分享入口。

如果你只是第一次体验，优先点示例课程包。它不需要上传真实资料，也不会暴露你的私人文件。

## 示例课程适合做什么

示例课程主要用来快速了解页面结构：

- 知识库里如何阅读知识文档。
- 知识图谱如何展示知识点关系。
- 训练中心如何生成练习。
- 课程画像如何展示掌握度。

示例课程不是你的真实学习记录。正式学习时，还是建议用自己的资料和目标重新构建课程。

## 导入课程前看什么

导入前先确认三件事：

| 检查项 | 为什么重要 |
| --- | --- |
| 课程主题 | 避免导入和当前学习目标无关的课程 |
| 资料来源 | 确认课程内容是否可信 |
| 可见范围 | 团队课程可能包含共享成员能看到的学习内容 |

不要把真实密钥、账号密码、内部接口地址或私人联系方式写进课程说明、资料文件名和分享备注。

## 导入后怎么用

导入成功后，建议按这个顺序检查：

```text
看课程首页 -> 打开知识库 -> 看一章知识文档 -> 打开图谱 -> 做一组小测
```

如果发现课程内容不符合预期，可以重新导入别的课程，或者回到首页用自己的目标新建课程。
