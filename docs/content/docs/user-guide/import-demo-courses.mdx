title: 导入、导出与分享课程
description: 先用演示课程体验完整功能，再安全地复用课程包或分享课程内容。
---

首页下方的精选演示课程是最快的体验入口。点击“加入课程”后，可以直接查看知识文档、图谱、训练中心和画像，不需要先准备资料或等待构建。

## 三种复用方式

| 方式 | 适合场景 | 是否包含你的学习记录 |
| --- | --- | --- |
| 演示课程 | 第一次体验产品 | 不包含你的历史记录 |
| `.atmx` 课程包 | 备份、迁移或离线分享完整课程 | 取决于导出时包含的内容 |
| 课程分享链接 | 让别人导入已发布的知识文档 | 不包含 |

导入后先检查课程标题、知识文档、资料来源和训练内容是否完整，再开始正式学习。

## 导出前必须检查

- 课程标题、说明和资料文件名是否含真实姓名或内部项目名。
- 知识文档是否引用了不应外发的原文或图片。
- 对话、考试和画像是否属于个人学习记录。
- 分享对象是否需要完整课程，还是只需要可阅读内容。

<GuideCallout title="课程包不是普通压缩包" tone="warning">
  不要随意修改 `.atmx` 内部文件。导入会恢复课程级文档、图谱和相关资产；来源不可信的课程包不要导入。
</GuideCallout>

## 导入失败时

先确认课程包完整、版本受支持并且存储空间可用。普通 `.atmx` 每次导入都会创建一份新课程，不要连续重复点击；失败时先查看提示，再决定是否重试。课程分享链接只包含已发布的知识文档，不包含原始资料、对话、考试或课程画像。
