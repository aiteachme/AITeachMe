title: 架构总览

---

AITeachMe 的核心对象是 `Course`。资料、知识文档、知识图谱、对话、测验和画像都围绕课程隔离。

## Course 边界

```text
Course
  -> RawFile
  -> Ingest: raw markdown + assets
  -> Digest Planner: confirmed plan
  -> Digest DocGen: knowledge docs + manifest
  -> KG sync: KnowledgeUnit / KnowledgeEdge
  -> Interact / Examine / Profile consume course assets
```

## 后端依赖方向

唯一推荐方向：

```text
api -> workflows -> repositories / shared.infra / models / schemas
shared.infra -> shared.kernel
```

简单判断：如果一段代码理解具体教学语义，它应该在 workflows；如果只是接 LLM、检索、存储、工具或观测，它才属于 shared.infra。

## 五大引擎

| 引擎 | 稳定职责 |
| --- | --- |
| Ingest | 保存上传文件，生成 raw markdown 和资产 |
| Digest | 生成 confirmed plan、知识文档和知识图谱 |
| Interact | 管理会话和课程问答 |
| Examine | 生成题目、组卷、判卷并写回画像 |
| Profile | 更新掌握度、薄弱点、复习任务和学习画像 |

## 不推荐的方向

- repositories 不依赖 workflows。
- shared.infra 不依赖具体 workflow lane。
- API 层不直接拼装复杂教学业务。

更细的配置、部署和数据目录规则以内部 `docs/`、模块 README 和当前代码为准。
