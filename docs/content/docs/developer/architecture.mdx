AITeachMe 不是通用 Agent 平台，也不是单次摘要工具。它是一套围绕 Course 运行的学习闭环。

## Course first

```text
Course
  -> RawFile
  -> Ingest: raw markdown + assets
  -> Digest Planner: confirmed plan
  -> Digest DocGen: knowledge docs + manifest
  -> KG sync: KnowledgeUnit / KnowledgeEdge
  -> Interact / Examine / Profile consume course assets
```

上传资料、知识文档、知识图谱、对话、测验和画像都围绕同一个课程隔离。

## 后端依赖方向

唯一推荐方向：

```text
api -> workflows -> repositories / shared.infra / models / schemas
shared.infra -> shared.kernel
```

不要反向依赖：

- repositories 不依赖 workflows。
- shared.infra 不依赖具体 workflow lane。
- API 层不直接拼装复杂教学业务。
- 旧 `services` 和旧 `teaching` 源层不恢复。

## 五大引擎

| 引擎 | 稳定职责 |
| --- | --- |
| Ingest | 保存上传文件，生成 raw markdown 和资产 |
| Digest | 生成 confirmed plan、知识文档和知识图谱 |
| Interact | 管理会话和课程问答 |
| Examine | 生成题目、组卷、判卷并写回画像 |
| Profile | 更新掌握度、薄弱点、复习任务和学习画像 |

## 运行形态

| 形态 | 典型用途 |
| --- | --- |
| 本地开发 | 调试前后端、workflow、解析器和模型接入 |
| 桌面本地版 | 面向个人本机使用，保留本地数据目录 |
| 云端部署 | 面向团队或内部验证环境，使用云端数据库和对象存储 |
| `.atmx` 课程包 | 课程知识资产迁移、分发和复用 |

## 配置归属

| 类型 | 位置 |
| --- | --- |
| 项目默认非敏感 settings | `shared/infra/settings/defaults.py` 和可选 override |
| 用户级非敏感 settings | 用户数据库中的 runtime settings |
| 环境变量和敏感项 | `.env` 或部署环境 |

密钥不写入用户 settings 数据库。旧 key 应按当前 schema 投影，无法识别的配置应被忽略。
