本地开发优先支持 Windows。文件读写和终端输出尽量使用 UTF-8。

## 后端

推荐使用项目约定的 Conda 环境：

```powershell
conda activate atm
cd backend
$env:PYTHONUTF8 = "1"
pip install -e .
uvicorn app.main:app --reload --reload-dir app --port 9020
```

默认本地数据目录：

```text
backend/data/
```

默认 SQLite 文件：

```text
backend/data/aiteachme.db
```

## 前端

```powershell
cd frontend
npm install
npm run dev
```

默认前端端口是 `5180`。开发模式通过 Vite 代理把 `/api` 转发到 `http://127.0.0.1:9020`，把 `/docs` 转发到本地文档站。

## 文档站

```powershell
cd docs
npm install
npm run dev
```

文档站默认运行在 `5182`，避免和主前端进程冲突。用户入口仍然可以走主前端地址：

```text
http://127.0.0.1:5180/docs
```

`5182` 只是 Vite 代理背后的内部目标。

## 根目录开发脚本

仓库根目录提供 Windows 开发脚本：

```powershell
.\dev.bat
```

脚本会优先复用已有端口，也支持通过 `.env` 或环境变量覆盖：

```ini
AITEACHME_BACKEND_PORT=9020
AITEACHME_FRONTEND_PORT=5180
AITEACHME_CONDA_ENV=atm
```

## 最小模型配置

根目录 `.env.sample` 是本地用户侧变量的主要参考。最小示例：

```ini
APP_MODE=local
AUTH_ENABLED=false
LLM_API_KEY=<model-api-key>
LLM_BASE_URL=https://api.example.com/v1
```

未开启鉴权的本地模型网关可以不填 `LLM_API_KEY`。实际模型槽位也可以在设置页或项目 settings override 中配置。
