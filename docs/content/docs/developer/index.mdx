AITeachMe 是前后端分离、可本地运行、可云端部署的 AI 学习系统。开发者文档只描述长期稳定的边界、入口和检查方式。

## 一句话架构

```text
frontend React
  -> FastAPI api
  -> workflows
  -> repositories / shared.infra / models / schemas
  -> SQLite/PostgreSQL + local/S3 storage
```

## 代码边界

| 区域 | 职责 |
| --- | --- |
| `frontend/` | React 应用、课程页面、对话、文档阅读和桌面壳 |
| `backend/app/api/` | HTTP 路由、鉴权依赖、请求响应转换、SSE 包装 |
| `backend/app/workflows/` | 唯一业务层，承接五大引擎和 support 用例 |
| `backend/app/shared/infra/` | LLM、检索、工具、存储、workflow runtime、观测等通用能力 |
| `backend/app/repositories/` | 数据库读写封装 |
| `backend/app/models/` | 持久化模型 |
| `backend/app/schemas/` | API 和 workflow 边界数据结构 |

## 开发原则

1. `Course` 是业务隔离边界。
2. `workflows/` 是唯一业务层。
3. `shared.infra` 只接通用能力，不理解教学语义。
4. `api` 优先调用 workflows，不直接拼装复杂业务。
5. `frontend/src/api/generated/` 由 Orval 生成，不手动修改。
6. 长链路 AI 任务必须有状态、进度、trace 和失败摘要。
7. 架构变化先更新模块 README，再同步展示文档。
