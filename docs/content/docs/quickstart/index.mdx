title: 快速开始
description: 用最少步骤理解首页入口，并跑通第一门 AITeachMe 课程。
---

第一次打开 AITeachMe 时，先把它理解成一个“从资料到课程”的学习工作台，而不是一个普通聊天框。

首页中心输入框默认用于构建课程：你写下学习目标，上传或选择资料，系统会先生成学习方案，再进入课程构建。

## 建议路线

1. 先看 [跑通第一门课](/docs/quickstart/first-course)，确认从上传资料到生成课程的完整路径。
2. 再看 [构建课程还是先聊天](/docs/quickstart/course-vs-chat)，理解首页两个模式分别适合什么场景。
3. 如果已经有资料，优先上传资料并写清楚学习目标；如果还没想清楚，先进入自由对话澄清范围。

## 你应该记住的两件事

| 当前状态 | 推荐入口 |
| --- | --- |
| 已经知道要学什么 | 用“构建课程”，一句话写清目标、范围和产出 |
| 还不知道课程边界 | 用“先聊再建课”，让 AI 先帮你梳理问题 |

构建课程会创建课程空间，并进入学习方案确认；自由对话更适合临时问答、资料解释和目标澄清。
