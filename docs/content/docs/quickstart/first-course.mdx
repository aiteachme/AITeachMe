这条路径适合第一次体验 AITeachMe。目标不是配置完整生产环境，而是在最短时间内看到一门课程开始成形。

## 你会完成什么

完成后，你应该能看到：

1. 一个新的课程空间。
2. 已上传并解析的学习资料。
3. 一份可确认的学习方案。
4. 生成中的知识库，以及后续训练中心和课程画像入口。

## 准备

如果你已经能打开 AITeachMe，直接从下一步开始。

如果你是在本地开发环境第一次运行，最简单的方式是在仓库根目录执行：

```powershell
.\dev.bat
```

启动后打开 `http://localhost:5180`。更完整的前后端命令在 [本地开发](/docs/developer/local-development)。

## 第一步：打开首页

首页中心输入框默认是“构建课程”模式。它不是普通聊天框，而是用来描述你想生成的课程。

![首页构建课程输入框](/screenshots/home-course-builder.png)

_先确认上方是“构建课程”模式，再写目标。示例截图已隐藏具体课程名和资料名。_

可以这样写：

```text
某门课期末冲刺，考试范围到老师划定的最后一章。我基础一般，想按考点生成课程、讲义和练习。
```

如果你已经有资料，先上传资料，再写一句目标会更好。

一个好目标通常包含：

| 信息 | 示例 |
| --- | --- |
| 学习主题 | 某门课程的期末复习、某个证书考试、某章专题 |
| 当前基础 | 基础一般、只学过前几章、题目能看懂但不会做 |
| 资料范围 | 讲义、题库、错题、考试范围说明 |
| 希望产出 | 课程大纲、讲义、例题、练习、复习计划 |

## 第二步：上传资料

点击输入框下方的“上传资料”或“选资料”。

![从资料库选择课程资料](/screenshots/library-picker.png)

_已经上传过的文件可以直接从资料库选择。文档站截图会对具体文件名做脱敏；真实使用时看状态即可。_

首次上传新资料：

1. 点击“上传资料”。
2. 选择本地文件。
3. 等待资料进入解析流程。
4. 状态变成“已就绪”后，再回到课程目标输入框。

从资料库选择已有资料：

1. 点击“选资料”。
2. 勾选状态为“已就绪”的资料。
3. 点击“确认选择”。
4. 回到输入框，确认能看到已选择的资料数量。
5. 补充课程目标后再发送。

适合上传：

- PDF、Word、PPT、Markdown、TXT。
- 教材章节、课程讲义、题库、错题、复习提纲。
- 图片资料也可以上传，但效果取决于本地或云端解析配置。

上传后系统会先进入资料解析。解析完成前也可以先描述课程目标，但高质量课程通常需要等待资料进入可用状态。

## 第三步：进入学习方案确认

点击发送后，系统会创建课程并进入方案确认页。这个阶段重点不是立刻生成长文档，而是确认学习路径。

![学习方案确认页](/screenshots/build-plan.png)

_学习方案页会列出章节、重点和构建入口。方案不对时先反馈调整，不要急着开始构建。_

- 课程目标是否对。
- 章节顺序是否合理。
- 重点和练习安排是否符合你的考试或学习场景。
- 资料是否已经被正确纳入。

如果页面出现“前置诊断”，先完成选择题或补充说明。你也可以跳过诊断，再点击“应用诊断”，系统会继续生成可确认的最终方案。

确认方案后，再点击“开始构建”，系统才会正式构建知识库。

## 第四步：等待知识库构建

构建过程中你会看到进度、草稿预览或阶段提示。完成后，课程通常会出现这些入口：

| 页面入口 | 用途 |
| --- | --- |
| 知识库 | 阅读知识文档、查看知识图谱、围绕课程内容追问 |
| 训练中心 | 生成测验、练习题或考卷，并查看错因 |
| 课程画像 | 查看掌握度、薄弱点和复习建议 |

## 如果没有成功

| 现象 | 先检查 |
| --- | --- |
| 上传失败 | 文件格式、文件大小、网络状态 |
| 解析很慢 | 资料页数、扫描清晰度、图片文字识别能力 |
| 课程没有构建 | 是否填写目标、是否完成或跳过前置诊断、是否确认方案 |
| 对话没有引用资料 | 资料是否已就绪、当前是否在这门课里提问 |
| 模型无响应 | 模型设置页；本地开发时再检查 `.env` 和后端日志 |

第一次体验时，建议先用一份较短的 PDF 或 Markdown。资料越清晰，课程越容易生成得稳定。
