title: 5 分钟开始

五分钟足够把资料和目标交给 AITeachMe，并拿到一份可以校对的课程方案。完整知识库通常还需要几分钟构建，期间可以离开页面，回来后继续。

<GuideCallout title="想先看看成品？">
  首页下方有精选演示课程。点“加入课程”即可进入已经构建好的知识文档、训练中心和课程画像，不需要先上传自己的文件。
</GuideCallout>

## 先选一份核心资料

第一次不要把整个资料文件夹都塞进来。选一份结构清楚、与目标直接相关的讲义或笔记即可；没有资料也可以只写目标开始。

<GuideSteps>
  <GuideStep number={1} title="上传或选择资料">
    在首页点击“上传资料”，或从资料库选择已经解析完成的文件。优先使用 1–3 份核心资料。
  </GuideStep>
  <GuideStep number={2} title="写清楚课程目标">
    说明要学什么、覆盖哪些范围，以及考试、时间或基础限制。目标越具体，课程边界越稳定。
  </GuideStep>
  <GuideStep number={3} title="提交并校对方案">
    系统先生成课程方案。确认章节、重点和资料范围无误后，再开始正式构建。
  </GuideStep>
</GuideSteps>

## 写一句能约束课程的话

把主题、范围和目的放在一句话里：

<PromptExample>
  我想用三天复习线性代数期末考试，重点覆盖向量组线性相关、矩阵的秩、线性方程组和特征值；请按先概念后题型的顺序组织课程。
</PromptExample>

只有“帮我学这个”时，系统无法判断难度、取舍和产出顺序。资料不能替代目标，同一套讲义既可以做成基础课，也可以做成考前冲刺课。

## 开始构建前检查方案

<ProductShot
  src="/screenshots/build-plan-current.png"
  alt="AITeachMe 课程方案页面，展示生成的学习路径和资料"
  caption="方案页保留了构建对话。指出要删改的章节或难度，系统会基于当前方案继续调整。"
/>

开始构建前至少检查四件事：

- 章节是否覆盖你的真实范围，而不是泛泛扩展。
- 前置知识和章节顺序是否适合当前基础。
- 上传的资料是否都已出现，是否混入无关文件。
- 练习和诊断安排是否符合你的时间。

<GuideCallout title="方案不对就直接改" tone="warning">
  例如：“删掉超出考试范围的第六章，把矩阵的秩提前到方程组之前，每章只保留一个典型题型。”比重新写一段模糊目标更有效。
</GuideCallout>

## 构建完成后从哪里开始

先进入 **知识库** 阅读第一章，再完成一轮短路径：

1. 在知识文档中找到本章的核心概念。
2. 用划选问答或课程问答解决阅读断点。
3. 做一组小测验，并逐题核对题目与题解。
4. 根据讲评和复习指南补齐薄弱点。
5. 积累几次真实作答后，再用课程画像安排复习。

不要一上来就生成大考卷。先读一章，再用一组短测检查系统是否抓住了真正的重点。
