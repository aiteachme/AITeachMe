title: 跑通第一门课
description: 从上传资料到生成课程，用一条最短路径体验 AITeachMe。
---

这条路径适合第一次体验 AITeachMe。目标不是配置完整生产环境，而是在最短时间内看到一门课程开始成形。

## 你会完成什么

完成后，你应该能看到：

1. 一个新的课程空间。
2. 已上传并解析的学习资料。
3. 一份可确认的学习方案。
4. 生成中的知识文档、知识图谱和后续学习入口。

## 准备

本地开发时通常需要两个进程：

```powershell
# 后端
conda activate atm
cd backend
uvicorn app.main:app --reload --reload-dir app --port 9020
```

```powershell
# 前端
cd frontend
npm install
npm run dev
```

前端默认运行在 `http://localhost:5180`，开发模式会把 `/api` 转发到后端。

> 如果你只想快速启动 Windows 开发环境，可以在仓库根目录运行 `.\dev.bat`。脚本会优先复用已有端口。

## 第一步：打开首页

首页中心输入框默认是“构建课程”模式。它不是普通聊天框，而是用来描述你想生成的课程。

可以这样写：

```text
高数期末冲刺课，考试范围到定积分应用。我基础一般，想按考点生成课程、讲义和练习。
```

如果你已经有资料，先上传资料，再写一句目标会更好。

## 第二步：上传资料

点击输入框下方的“上传资料”或“选资料”。适合上传：

- PDF、Word、PPT、Markdown、TXT。
- 教材章节、课程讲义、题库、错题、复习提纲。
- 图片资料也可以上传，但效果取决于本地或云端解析配置。

上传后系统会先进入资料解析。解析完成前也可以先描述课程目标，但高质量课程通常需要等待资料进入可用状态。

## 第三步：进入学习方案确认

点击发送后，系统会创建课程并进入方案确认页。这个阶段重点不是立刻生成长文档，而是确认：

- 课程目标是否对。
- 章节顺序是否合理。
- 重点和练习安排是否符合你的考试或学习场景。
- 资料是否已经被正确纳入。

确认方案后，系统才会开始正式构建知识文档。

## 第四步：等待知识文档和图谱

构建过程中你会看到进度、草稿预览或阶段提示。完成后，课程通常会出现这些入口：

- 知识文档：像讲义一样阅读课程内容。
- 知识图谱：查看知识点和关系。
- 伴读问答：围绕课程资料追问。
- 诊断练习：生成测验并查看错因。
- 学习画像：查看掌握度和薄弱点。

## 如果没有成功

| 现象 | 先检查 |
| --- | --- |
| 上传失败 | 文件格式、文件大小、后端日志 |
| 解析很慢 | OCR/文档解析配置、资料页数 |
| 课程没有构建 | 是否填写目标、是否确认方案 |
| 对话没有引用资料 | 课程是否已有知识文档或可检索资料 |
| 模型无响应 | `.env`、模型设置页、后端日志 |

第一次体验时，建议先用一份较短的 PDF 或 Markdown。资料越清晰，课程越容易生成得稳定。
