---
title: 构建课程还是先聊天
description: 解释首页输入框两个入口的差异，帮助用户知道该如何开口。
---

首页输入框有两个稳定入口：**构建课程** 和 **先聊再建课**。它们都能使用资料，但目标不同。

## 构建课程

当你已经知道要学什么，或者已经准备好资料时，用“构建课程”。

![首页构建课程和先聊再建课两个模式](/screenshots/home-course-builder.png)

_“构建课程”会走课程生成链路；“先聊再建课”更像学习顾问，会先帮你澄清目标。示例截图已隐藏具体资料名。_

适合这样说：

```text
我想做一门综合基础课冲刺，资料是题库和讲义。目标是两周内掌握几个核心模块的常考点。
```

系统会把你的描述理解成课程目标，并进入学习方案确认。确认后才开始正式生成知识文档和图谱。

## 先聊再建课

当你还不确定课程边界时，用“先聊再建课”。

![全页自由对话入口](/screenshots/assistant-chat.png)

_自由对话会以全页方式展示，更适合连续讨论、先上传资料再一起分析，或者临时解释概念。_

适合这样说：

```text
我复习效率很低，资料也有点乱。先帮我判断应该补哪些基础，再决定要不要生成课程。
```

系统会先像学习顾问一样对话，必要时再调用工具或引导你转成课程。

## 怎么选择

| 当前状态 | 推荐入口 |
| --- | --- |
| 已有明确考试范围 | 构建课程 |
| 已上传一组资料，想直接生成课程 | 构建课程 |
| 只是有困惑，还不知道课程主题 | 先聊再建课 |
| 想让 AI 先问几个问题再定目标 | 先聊再建课 |
| 想查资料、解释概念、临时问答 | 先聊再建课 |

## 一个好请求的结构

不需要写很长，三句话就够：

1. 你要学什么。
2. 你当前基础如何。
3. 你希望系统产出什么。

示例：

```text
我想做一门技能入门课。目标是能完成一个简单实践任务。我基础一般，希望先学核心概念和基础操作，再安排练习。
```

## 重要边界

- 构建课程不是一次性摘要，它会创建课程空间。
- 自由对话可以帮助澄清目标，但不会自动替代课程构建确认。
- 上传资料后，系统仍需要你说明学习目标；资料本身不等于课程目标。

如果你还没想清楚，可以先用自由对话把问题聊明白，再把最后确认的目标复制到“构建课程”模式里提交。
