title: AITeachMe 是什么

---

AITeachMe 想解决的是“资料很多、问题很多、但学习路径很不清楚”的困境。

一句话：

```text
把学习资料变成可讲、可问、可测、可追踪的课程空间。
```

## 它不是普通聊天框

普通聊天框回答一次问题。AITeachMe 更强调把学习资产沉淀在课程里：

- 上传资料后可以复用。
- 课程方案可以确认和调整。
- 知识文档可以持续阅读。
- 伴读问答可以回到课程上下文。
- 测验和画像可以沉淀学习表现。

## 五大引擎

| 引擎 | 面向用户的说法 |
| --- | --- |
| Ingest | 解析资料 |
| Digest | 生成课程、讲义和知识图谱 |
| Interact | 伴读问答 |
| Examine | 诊断练习和错因解释 |
| Profile | 学习画像和复习建议 |

这些名字主要帮助开发者理解系统结构。用户不需要记住引擎名，只要知道从资料到课程、从课程到练习、从练习到画像是一条闭环。

## 当前适合的场景

- 期末、考研、考证前，把资料整理成冲刺课程。
- 对一组课件、讲义、题库进行结构化复习。
- 学完一章后生成练习并复盘错因。
- 团队或个人希望在本地优先的环境里使用学习资料。

## 当前边界

- AI 生成内容需要核对，尤其是复杂公式、扫描件和来源不清的资料。
- 资料解析质量会影响后续课程质量。
- 学习画像需要测验和互动积累，刚开始时只适合做粗略参考。
- 本地或云端模型配置会影响速度、成本和可用能力。

AITeachMe 的设计方向是长期的，但文档站只承诺当前稳定的使用方式和开发边界。
