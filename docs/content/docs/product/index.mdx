AITeachMe 想解决的是“学习资料很多，但不知道怎么学”的问题。

它会把资料、课程、对话、练习和画像放在同一个学习空间里，让用户不只是问一个答案，而是逐步形成自己的学习闭环。

## 先读这一篇

如果你只是想快速理解产品，请看 [什么是 AITeachMe](/docs/product/what-is-aiteachme)。

那篇文档会用更短的方式解释：

1. AITeachMe 和普通 AI 聊天框有什么不同。
2. 五大引擎分别负责什么。
3. 当前版本适合哪些学习场景。
4. 哪些能力仍然在迭代中。
