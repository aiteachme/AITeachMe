# 自定义题型功能及历史数据清理

2026-10-12：训练中心仅保留单选、多选、判断、填空、简答五种常规题型。

## 清理范围

- 移除题型包导入、示例下载、注册、版本管理、启停、归档，以及自定义出题和判分链路。
- 删除历史自定义题目、包含这些题目的试卷、引用自定义题型配置的失败或预生成记录，以及关联答案、知识点关联、讲评缓存和评分/画像任务。
- 混合试卷按整卷删除，避免保留不完整的题量和成绩；其中的常规题库模板保留。
- 删除题型包表、ORM 模型、专用快照及结构化答案字段、历史只读标记和展示组件，重新生成 OpenAPI 和前端客户端。
- 常规题型配置、作答草稿隔离、提交后禁止修改答案、闯关准备时机及题库缓存修复继续生效。
- 含自定义题型的旧课程包仍被拒绝导入，避免重新写入已移除的数据。

## 数据库升级

- SQLite 在结构检查前执行一次清理，自动备份到数据库同级的 backups/custom-type-cleanup-*.db。删除与表结构调整处于同一事务，失败回滚，完成后重复启动不会再次清理。
- PostgreSQL 提供 20261012_0033 Alembic 迁移；此前已发布的迁移文件保留。该迁移包含有意的数据删除，升级前须备份，不能通过 downgrade 恢复被删记录。本次未连接或迁移云端数据库。
- 删除已进入画像统计的答卷时，失效的画像聚合通过现有任务队列从保留的常规答卷重新计算。
- 清理事务同时作废受影响课程及用户的持久化画像缓存，即使没有剩余已评分答卷或掌握度记录，也不会让文档生成继续读取旧画像。无关课程和用户的缓存保留；事务失败时缓存变更一并回滚。
- SQLite 的题目、试卷编号保持递增，不复用已删除记录的编号，避免旧链接或浏览器草稿指向新记录。

## 执行后核查

- 对照清理前备份，确认课程内容和保留的常规题目、试卷完整。
- 检查数据库完整性、外键以及应用结构，确认自定义题型表和字段已移除。
- 实际数据库、备份及包含本地数据的核查报告不纳入 Git。

## 验证

- 迁移测试覆盖真实旧版 DDL、混合试卷删除、常规数据保留、失败回滚、重复执行、自动备份、编号防复用和画像任务重建。
- 画像缓存回归覆盖有/无剩余已评分答卷、有/无掌握度记录四种组合，以及文档生成读取、缓存清理范围和失败回滚。
- 后端回归覆盖常规出题、评分、题库、闯关、画像、课程导入导出、删除及 SQLite 升级；前端相关测试与生产构建通过。
- OpenAPI 同步检查和 PostgreSQL 离线迁移 SQL 检查通过。PostgreSQL 迁移未在真实服务上执行。
- 清理后的数据库副本已通过 HTTP 检查：五种常规题型、题库、历史试卷和正常答卷可读取，被清理的答卷返回 404。本次未调用模型。
