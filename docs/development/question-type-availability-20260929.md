# 题型目录与出题配置数量差异审查

日期：2026-09-29。

## 结论

截图对应课程登记了 5 个系统题型和 2 个上传题型。当前数据库和课程题型 API 均显示：结构化辩论题的 `status=inactive`、`is_active=false`，但 `runtime_ready=true`，已有当前安装版本并支持测验、考卷、闯关；费曼解释题为启用状态。因此目录总数为 7，出题配置为 6。

出题配置排除已停用题型的行为正确。现有数据没有记录停用操作的来源，无法据此判断是谁或哪个历史流程停用了它。该差异不要求把现有 v1 题型包升级到 v2。

## 已修复问题

1. 题型详情缺少启用、停用操作，已安装且可运行的题型无法从界面重新启用。现在复用现有 PATCH 接口切换状态；待接入版本不能启用；归档题型仍先恢复到目录，再启用。
2. 状态筛选把运行能力已就绪的停用题型归入“可用”。新增“已停用”分类，并让分类、状态标签和出题配置共用可用性判断。
3. 概览只有登记总数，详情还向已就绪题型显示“运行能力发布后可用”。现在展示测验、考卷、闯关各自的可用数量，以及停用、待接入、归档数量；详情按实际状态说明下一步操作。

题型状态更新沿用目录与训练中心共享的查询缓存，返回训练中心后配置立即反映新状态。用户课程中的停用记录没有被自动改为启用。

## 验证

- 前端针对题型可用性、训练配置、自定义作答字段的 20 项测试通过，其中新增 6 项可用性回归测试。
- 后端题型包 API、安装与状态管理的 20 项测试通过。首次运行被原有 `backend/pytest-tmp` 目录访问权限阻塞，改用本次独立临时目录后通过；有 1 条既有 Starlette 弃用提示。
- `npm run build` 通过；仍有既有大体积产物提示。
- 独立数据库导入旧版结构化辩论题 1.0.0、费曼解释题 1.0.1，设置辩论题停用，复现“登记 7、可用 6”。
- 浏览器验证“已停用”筛选只显示辩论题；点击启用后统计立即变为 7，测验、考卷、闯关均显示 7 个题型选项，均可选中辩论题并保存配置。
- 再次停用后，三个配置窗口均恢复为 6 个选项。之前保存的辩论题选择被识别为不可用，阻止继续保存无效配置。

本次验证针对状态变更和配置联动，没有重新调用模型进行生成或评分。

## 用户操作

刷新网页，打开“课程题型 → 结构化辩论题 → 启用题型”，再返回训练中心打开出题配置。现有两个上传题型都支持三个训练场景，启用后它们的配置列表均为 7 种。
