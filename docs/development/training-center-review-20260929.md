# 训练中心实现审查与回归测试

日期：2026-09-29。范围：当前工作区的题型包导入、V1/V2 运行合同、出题、题库、测验、考卷、一次性闯关、评分、历史、画像隔离及导出导入。

后续进展：本页保留本轮逻辑审查时点的结果。同日随后主模型连接恢复，已执行真实模型和浏览器/PDF 验收，后端回归扩大至 441 项；当前状态以 [P4 验收记录](question-type-p4-review.md) 为准。

## 结论

主要职责划分合理：support 校验和安装题型包，question_types 解析冻结版本与作答合同，question_build 生成草稿，API 保存权威快照，exam_grade 验证证据并计算成绩，前端按字段 key 展示。V1 兼容与 V2 自由文本字段复用同一内部定义。

本轮复现并修复六类问题。新增回归先在修复前失败，再验证修复后的行为；原有相关测试同时通过。代码正确性证据不等同于真实模型出题、评分或教学质量的发布验收。

## 已修复问题

| 问题 | 触发与影响 | 修复及回归依据 |
| --- | --- | --- |
| 导入与评分的权重规则不同 | 合计 0.99975 的权重可以通过包校验，评分却要求误差不超过 0.000001，导致合法包无法评分 | 校验和评分共用 0.001 容差；只在评分视图中归一化，不修改冻结快照。V1/V2 真包均验证了导入和满分评分 |
| 合法字段名与 Pydantic 属性冲突 | `model_dump` 使输出模型无法构造，`model_config` 被当作内部配置而丢失 | 内部属性使用独立名称，外部字段通过 alias 保留；验证 Schema、必填校验与参考答案往返 |
| 前端读取对象原型属性 | 字段名为 `constructor` 且答案对象为空时，会读取 Object 构造函数文本并判为已作答 | 仅从答案对象自身属性取值；验证空白识别和真实输入 |
| 省略多字段题不能交卷 | 部分作答请求省略一道多字段题，被误判为缺少结构化答案 | 仅对整题省略补齐空字段；显式对象仍严格校验。省略题目与显式空答案的提交指纹一致 |
| 反馈 prompt 未生效 | `feedback.md` 已保存，但评分请求没有携带它 | 同一次评分请求注入反馈指导，只影响反馈表达。增加冻结字段与难度上下文，确认一次调用并由服务端计算分数 |
| 公开错误直接包含底层异常 | 生成详情、SSE 或预生成状态直接显示 LiteLLM、认证异常及内部细节 | 公开投影将认证、停用、超时等错误转成可操作说明；内部诊断保持原值。保留已有中文业务错误文案 |

新增后端用例位于 [test_training_review_regressions.py](../../backend/tests/test_training_review_regressions.py)；前端用例位于 [custom-question-fields.test.mjs](../../frontend/tests/custom-question-fields.test.mjs)。

## 逻辑清晰度

| 范围 | 评价 | 当前处理与后续建议 |
| --- | --- | --- |
| 导入、运行与快照 | 职责明确 | 保留声明式包、不可变版本与服务端权威字段，避免另建一套插件执行系统 |
| 字段和评分合同 | 数据流清楚，此前有边界不一致 | 本轮修复字段名称、未作答语义和权重容差；测试同时检查结构和结果 |
| LLM 与反馈 | 依赖复用正确 | `llm()` 复用现有 helper；反馈并入评分请求；模型异常不应转为错误成绩 |
| 训练入口与 API | 编排职责过于集中 | `backend/app/api/exams.py` 约 8,000 行，`ExamsPage.tsx` 约 4,800 行。后续宜按选择/组卷、提交/评分、题库/闯关、公开序列化拆分，配合现有回归逐步迁移 |
| 文档与代码 | 发现明显过时说明 | 修正了“仅费曼可执行”“未知题型走主观判分”“模型失败退回文本匹配”“客观题另调模型反馈”等说明 |

评分/反馈变量现在明确按阶段解释：提供课程名、本题难度、冻结字段、rubric 和参考案例；不重读可变课程描述或知识图谱，`course_description` 和 `knowledge_units` 分别为空字符串和空数组。题干、参考答案和学生回答继续作为实际评分依据。

大文件拆分属于维护性改进，本轮没有进行大范围搬迁；当前证据不足以把文件体积本身判定为功能错误。

## 剩余验收边界

当前已知主模型密钥被上游停用，备用连接缺少网关地址；本轮使用固定模型返回值验证业务合同，没有将其记作真实模型端到端通过。需要有效模型连接后，再完成独立人工案例的质量评估、模型时延与成本、部署环境完整训练路径和移动端回归。

功能范围仍为单次文本作答；多轮交互、语音、图片和代码执行需要独立的平台能力。
