## 五、速成课 vs 系统课 — 双模式文档生成策略

### 5.1 两种模式的本质区别

| 维度 | 速成课 (Sprint) | 系统课 (Systematic) |
|:---|:---|:---|
| **目标用户** | 期末周极限突击的大学生、考前冲刺 | 考研党、系统学习者、需要反复精读 |
| **核心价值** | 用最少时间抓住最多分数 | 建立完整知识体系，深度理解 |
| **文字量** | 3000-5000 字（精炼） | **10000-15000 字**（详尽） |
| **章节数** | 锁死 4 节 | 6-10 节（按知识深度自适应） |
| **重点内容** | 范例题 > 公式速记 > 易错点 > 概念 | 知识脉络 > 定理证明 > 概念辨析 > 应用 |
| **公式处理** | 公式 + 大白话翻译 + 秒杀口诀 | 完整推导 + 条件分析 + 边界情况 |
| **出题策略** | 每节 2-3 道范例题（占比 40%） | 每节 1 道思考题（占比 10%） |
| **语言风格** | 轻松幽默、口语化、"学长带你飞" | 严谨专业、教科书级、"教授讲义" |
| **富媒体** | Mermaid 速记图 + 公式卡片 | Mermaid 知识脉络图 + 详细配图 + 表格对比 |

### 5.2 速成课章节固定结构

每个速成课**必须**包含以下 4 节，顺序固定：

```
第 1 节：概念破冰 🧊
├── 用生活实例引入（禁止直接写定义）
├── 核心概念的"大白话"解释
├── [MERMAID] 概念关系速记图
└── 本节速记卡（3 句话）

第 2 节：公式武器库 🔫
├── 所有核心公式（LaTeX 格式）
├── 每个公式后紧跟"大白话翻译"
├── > [!TIP] 秒杀口诀（如"左加右减上加下减"）
├── 公式适用条件表格
└── 本节速记卡

第 3 节：真题实战 ⚔️（重点！占比 40%）
├── 2-3 道精选范例题
├── 每题 STEP 1 / STEP 2 / STEP 3 详细推导
├── > [!WARNING] 易错点标注
├── 变型题提示（"如果把 x 换成 y 呢？"）
└── 本节速记卡

第 4 节：防坑指南 🕳️
├── Top 3 常见错误
├── 易混淆概念对比表格
├── 考试答题模板（"遇到 XX 题型，先写 XX，再算 XX"）
└── 全文速记总卡
```

### 5.3 系统课章节自适应结构

系统课的章节数由 `edu_planner` 根据学科复杂度自适应生成（6-10 节），但每节**必须**包含以下模块：

**章节数决策规则**（`edu_planner` 内部逻辑）：

```
系统课章节数 = clamp(ceil(预估知识点数 / 3), min=6, max=10)

决策依据优先级：
1. 如果用户上传了文件 → 参考文件的 header 数量作为知识点估计
2. 如果纯主题输入 → 由 Strategic LLM 自行判断，Prompt 中约束 "6-10 章"
3. 字数分配：总目标字数(10000-15000) / 章节数 = 每章目标字数
   → 写入 ChapterPlan.writing_instructions 中

速成课章节数 = 固定 4（MVP 阶段不可配置）
```

```
每节标准结构：
├── > 📌 前置知识：列出本节依赖的前置概念
├── 动机引入（为什么要学这个？解决什么问题？）
├── 核心定义 / 定理（> [!IMPORTANT] 标注）
├── 完整推导 / 证明（∵ ... ∴ ... 格式）
├── 应用示例（1-2 个）
├── 与相关概念的对比表格
├── [MERMAID] 本节知识在整体脉络中的位置
└── 本节要点（定理编号 + 一句话总结）
```

**系统课的额外要求**：
- 第 1 节必须是"全景导论"：用 Mermaid 画出整个学科/主题的知识脉络图
- 最后 1 节必须是"总结与展望"：回顾全文脉络 + 推荐进阶学习路径
- 公式必须完整推导，不允许"易证"或"显然"
- 文字量目标 **10000-15000 字**，通过 `edu_planner` 的 `writing_instructions` 中注入字数要求

### 5.4 语言风格配置

在 `edu_planner` 的输入中新增 `tone` 参数：

| tone 值 | 描述 | 适用场景 | Prompt 关键词 |
|:---|:---|:---|:---|
| `casual` | 轻松幽默，学长带飞 | 速成课默认 | "用口语化表达，可以用emoji，像学长在宿舍给你讲题" |
| `professional` | 严谨专业，教授讲义 | 系统课默认 | "用学术语言，严谨准确，像教授的课堂讲义" |
| `encouraging` | 温暖鼓励，陪伴式 | 基础薄弱用户 | "多用鼓励性语言，每个难点后加一句'别怕，我们一步步来'" |
| `concise` | 极简干练，纯干货 | 时间极紧用户 | "去掉所有废话，只保留公式、步骤、结论" |

**配置方式**：
```python
# DocGenState 新增字段
digest_mode: str    # "sprint" | "systematic"
tone: str           # "casual" | "professional" | "encouraging" | "concise"
```

### 5.5 为什么我们的文档比其他方案好？

#### 5.5.1 vs Deep Research（通用研究报告）

| 维度 | Deep Research | AITeachMe 知识文档 |
|:---|:---|:---|
| 内容风格 | 通用研究报告，面向所有人 | **教育定制**：速成课/系统课双模式，针对考试/学科设计 |
| 知识结构 | 平铺直叙，按搜索结果组织 | **教学法骨架**：Strategic LLM 按教学法规划章节顺序 |
| 公式处理 | 可能有公式但无推导 | **完整 LaTeX**：推导 + 大白话翻译 + 秒杀口诀 |
| 出题能力 | 无 | **联动 Examine 引擎**：自动生成趁热打铁考题 |
| 用户画像 | 无 | **Profile 引擎联动**：根据用户薄弱点定制内容深度 |
| 富媒体 | 纯文本 | Mermaid 思维导图 + AI 配图 + LaTeX 公式 |

#### 5.5.2 vs 直接问 AI（ChatGPT / Claude）

| 维度 | 直接问 AI | AITeachMe 知识文档 |
|:---|:---|:---|
| 系统性 | 单次问答，碎片化 | **完整文档**：从概念到应用的系统闭环 |
| 深度 | 受限于单次 context window | **多轮检索**：Plan-Execute 范式，每章独立搜索 + 压缩 |
| 可追溯 | 对话消失后无法回看 | **持久化文档**：存入 ContentStore，随时回看 |
| 个性化 | 每次都要重新描述需求 | **记忆系统**：Profile 引擎记住你的薄弱点 |
| 质量保障 | 可能幻觉 | **多源验证**：本地 RAG + 外网搜索 + 上下文压缩 |

#### 5.5.3 vs 自己看 PPT

| 维度 | PPT | AITeachMe 知识文档 |
|:---|:---|:---|
| 信息密度 | 受限于幻灯片版面，大量留白 | **Markdown 无限延展**：公式推导、表格对比、代码示例 |
| 交互性 | 静态翻页 | **响应式渲染**：Mermaid SVG、KaTeX 公式、暗色主题 |
| 可搜索 | 难以全文搜索 | **全文检索**：向量搜索 + 关键词搜索 |
| 更新成本 | 重新制作 | **一键重新生成**：修改 prompt 即可迭代 |
| 智能体时代 | PPT 是孤岛 | **Markdown 是智能体时代的血液**：可被 RAG 索引、可被 AI 理解、可被自动化流水线处理 |
