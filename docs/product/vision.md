# AITeachMe 产品愿景

AITeachMe 的愿景是：让天下没有难学的知识。

一句话定位：

> 把任何令人头疼的学习资料，变成你的 24 小时专属赛博私教。

用户只需要把资料交给系统，AITeachMe 会围绕同一个课程空间完成学习闭环：

```text
资料进入系统
  -> 提取知识内核
  -> 组织成学习方案和知识文档
  -> 支持伴读问答
  -> 生成诊断练习
  -> 沉淀掌握度和成长轨迹
```

## 解决的问题

现代学习最大的痛点不是缺资料，而是资料难以转化成高质量学习行为：

- 抓不住重点：材料很多，考点、主线和依赖关系不清楚。
- 陷入题海：刷了很多题，但对变式和底层概念掌握不足。
- 无人答疑：卡在一句“易证”或一个标准答案时，很难及时获得解释。
- 认知错觉：看书觉得会了，真实作答才发现薄弱点。
- 资源壁垒：高质量私教昂贵，公开 AI 又有数据和隐私顾虑。

## 五大引擎

### Ingest：透视引擎

把 PDF、Word、PPT、Markdown、文本、图片等材料转成标准 Markdown 和资产目录。目标是先快、可预览、可恢复，再逐步增强复杂资料质量。

### Digest：织网引擎

把资料组织成用户确认过的学习方案，再生成可阅读、可追踪、可复用的知识文档，并同步成知识图谱。

### Interact：伴读引擎

围绕课程、资料、知识文档、选中文本、错题和学习画像进行教学对话。目标不是直接甩答案，而是尽量解释过程、追问盲区、引导理解。

### Examine：诊断引擎

基于知识单元、薄弱点和复习任务生成试卷，支持作答、判卷、错因解释和学习建议。

### Profile：显影引擎

把每次学习、作答和复习沉淀为掌握度、薄弱点、复习任务和课程画像。MVP 阶段以统计量为主，后续可扩展 BKT、遗忘曲线或更细的认知诊断模型。

## MVP 边界

当前 MVP 优先保证：

- 本地优先可运行。
- 一个课程空间内资料、知识文档、知识图谱、对话、考试和画像互相打通。
- 数据结构和 workflow 边界足够清晰，后续可以平滑增强。

当前不追求：

- 一开始就成为全能 Agent。
- 自动推翻用户确认过的学习方案。
- 把所有历史设计中的课程树、教学单元和复杂版本表一次性恢复。

## 当前工程原则

- Course 是业务隔离边界。
- Workflows 是唯一业务层。
- Infra 只接能力，不决定教学策略。
- 文档以当前事实为准，不保留会误导开发的旧权威稿。
