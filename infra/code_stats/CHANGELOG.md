# 代码统计工具更新日志

## v2.0.0 - 2026-02-06

### 新增功能

#### 🚀 三种运行模式
1. **增量更新模式**（默认）
   - 只分析新提交，速度快（3-10秒）
   - 适合日常使用
   - 命令：`python generate_code_stats.py`

2. **完全重建模式**
   - 重新分析指定数量的历史提交
   - 可自定义提交数量
   - 命令：`python generate_code_stats.py --full [N]`

3. **完整历史模式**（新增）⭐
   - 分析所有 Git 历史提交
   - 自动采样为 100 个数据点
   - 适合首次运行
   - 命令：`python generate_code_stats.py --all`

#### 📊 智能采样
- 当提交数超过 100 时，自动采样
- 保证图表可读性
- 平衡历史覆盖和性能

#### 📁 文件组织
- 所有文件统一放在 `tools/code_stats/` 目录
- 更清晰的项目结构
